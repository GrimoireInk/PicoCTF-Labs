To build a strong foundation in Cybersecurity through command-line proficiency, scripting, file analysis, and practical problem-solving.

## 📖 Overview

This directory contains my solutions, technical write-ups, and supporting scripts for the **General Skills** category of PicoCTF.

These challenges focus on developing the fundamental technical skills necessary for cybersecurity, including navigating operating systems, working with files, interpreting data, and using programming languages to solve problems.

My goal is to document not only how I complete each challenge, but also the reasoning, commands, and concepts involved in reaching a solution. **WITHOUT** directly giving out the solution for one does not learn by being handed things.

## 🧠 Skills & Concepts

The General Skills category provides opportunities to develop proficiency in:

- **Command-Line Navigation:** Navigating directories and managing files using terminal commands.
- **Linux Fundamentals:** Understanding common Linux utilities, permissions, and filesystem structures.
- **Python Programming:** Writing and modifying scripts to automate tasks and solve challenges.
- **File Analysis:** Identifying file types, inspecting contents, and extracting relevant information.
- **Data Encoding:** Working with ASCII, hexadecimal, Base64, and other representations.
- **Problem-Solving:** Breaking down technical problems into manageable steps.
- **Technical Documentation:** Recording investigations, commands, findings, and lessons learned.

---

## 📝 Documentation Approach

My challenge write-ups aim to include:

1. **Challenge Overview** — The objective and information provided.
2. **Initial Analysis** — My observations and initial approach.
3. **Investigation** — Commands, tools, and techniques used.
4. **Solution Methodology** — An explanation of how the challenge was solved.
5. **Concepts Learned** — Technical knowledge gained.
6. **Key Takeaways** — Lessons applicable to future cybersecurity work.

Flags and sensitive information are intentionally omitted from public documentation.
